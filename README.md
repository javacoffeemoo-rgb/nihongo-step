# 🇯🇵 카카오톡 일본어 회화봇

카카오톡 대화방 안에서 **일본어 말하기를 연습**하는 챗봇입니다.
일본어 초보자가 **소리 내어 따라 말하며** 익히는 것에 초점을 맞췄습니다.

- **선생님을 고를 수 있어요** — 여성 유키 선생님 / 남성 타케시 선생님 (말투와 응원 방식이 달라요)
- 일본어 + 가나 + **한글 발음** + 뜻을 함께 보여줘서 읽을 줄 몰라도 바로 따라 말할 수 있어요.
- 설치 필요 없음: **Python 표준 라이브러리만** 사용합니다. (`pip install` 불필요)
- 카카오톡에 연결하기 전에, 브라우저에서 **카톡처럼 생긴 테스트 화면**으로 먼저 연습할 수 있어요.

> 🌐 **웹 학습장도 함께 있습니다.** 같은 콘텐츠로 브라우저에서 학습하고, 닉네임별로
> 진도가 서버(`data/progress/`)에 저장됩니다. → **http://localhost:8000**
> 기획서는 **[WEB_PLAN.md](WEB_PLAN.md)** 에 있습니다.

### 학습 콘텐츠 규모

| 항목 | 개수 |
|---|---|
| 커리큘럼 | **6단계 24과** ([CURRICULUM.md](CURRICULUM.md)) |
| 주제 | 6개 |
| 회화 상황 | **21개** |
| 회화 문장 | **126개** |
| 단어 | **124개** |
| 가나 | 히라가나·가타카나 92자 |

## 1. 바로 실행해보기

```powershell
python server.py
```

그다음 브라우저에서 **http://localhost:8000** 을 열어보세요.
**웹 학습장**이 열립니다. (닉네임을 입력하면 바로 시작)

| 주소 | 용도 |
|---|---|
| **http://localhost:8000** | 🌐 **웹 학습장** — 커리큘럼 학습 · 듣기(TTS) · 녹음 · 진도 저장 |
| **http://localhost:8000/legacy** | 💬 카톡 스타일 테스트 화면 — 봇 응답 미리보기 |

> Windows에서는 **`run.bat`**(서버만) 또는 **`run_tunnel.bat`**(서버 + HTTPS 터널)을 더블클릭해도 됩니다.
> `run_tunnel.bat`을 쓰면 폰에서 녹음·홈 화면 추가까지 바로 테스트할 수 있어요.

서버를 끄려면 실행 중인 창에서 `Ctrl + C` 를 누르세요.

### 웹 학습장에서 할 수 있는 것

- 6단계 24과를 **한 화면 한 문장**으로 학습 (일본어 + 한글 발음 + 뜻 + 팁)
- **🔊 듣기** — 브라우저 음성으로 일본어 발음 재생, 속도 조절(느리게/보통/빠르게)
- **🎤 3초 녹음** — 내 목소리와 원어를 번갈아 들으며 비교
- **✅ 과 확인 퀴즈** — 6문장을 다 본 뒤 한→일 4지선다 6문제로 확인
- **🔁 복습** — 틀린 문장이 자동으로 모이고, 맞히면 하나씩 사라짐
- **📖 단어장** — 124개 단어를 검색·카테고리로 보고 🔊 발음 듣기, **단어 퀴즈 10문제**
- **📊 학습 통계** — 연속일 · 완료 과 · 정답률 · 학습 시간, 최근 7일 그래프, 단계별 진도
- **가나 표** — 글자를 누르면 발음 재생, 6문제 읽기 퀴즈
- **닉네임 진도** — 문장 위치·완료 과·오답·연속일이 서버에 저장되어 새로고침해도 이어짐
- **선생님 · 하루 목표** — 설정에서 언제든 변경

### 📱 안드로이드 폰에서 쓰기

폰에서 많이 쓸 예정이라 **모바일(390px 기준) 우선**으로 만들었습니다.

1. 폰 브라우저에서 `http://<PC의 IP>:8000` 접속 (PC와 같은 와이파이에서)
2. Chrome 메뉴 → **홈 화면에 추가** → 앱처럼 전체 화면으로 실행됩니다
3. 한 번 열어두면 **오프라인에서도 앱 껍데기**는 열립니다 (문장은 서버 연결 필요)

> 폰 실기 확인은 **[MOBILE_QA.md](MOBILE_QA.md)** 체크리스트를 순서대로 따라 하세요.
> `http://IP` 접속에서는 브라우저 규칙상 **녹음·앱 설치·오프라인이 차단**됩니다
> (듣기·학습·진도 저장은 정상). HTTPS 배포 또는 ngrok 터널이면 모두 풀립니다.

적용된 것: 하단 고정 내비(홈·커리큘럼·복습·설정), 48px 이상 터치 타깃,
`100dvh`(주소창 높이 변화 대응), 안전 영역 패딩, 두 번 탭 확대 방지,
Android 기본 일본어 폰트(Noto Sans JP) 우선, PWA 매니페스트 + 서비스 워커,
PNG 앱 아이콘(512, `maskable` 대응 — 런처에서 잘 보임).

### 콘텐츠 추가하기

`data/scenarios.json` 에 문장을 추가하면 바로 반영됩니다.
`cat` 값은 `basic / food / shop / move / travel / daily` 중 하나입니다.

```json
{
  "id": "onsen",
  "cat": "travel",
  "emoji": "♨️",
  "title": "온천에서",
  "desc": "온천 이용 예절을 물어봐요",
  "level": "초급",
  "steps": [
    {
      "ja": "おふろは なんじまでですか。",
      "kana": "お風呂は何時までですか",
      "pron": "오후로와 난지마데데스카",
      "ko": "목욕탕은 몇 시까지예요?",
      "tip": "まで = ~까지."
    }
  ]
}
```

`data/words.json` 도 같은 방식입니다. 서버를 다시 시작하면 적용됩니다.

### 선생님 말투 바꾸기

## 4. 진짜 카카오톡에 연결하기

여기서부터는 **카카오 담당자 승인 절차**가 포함됩니다. 순서대로 따라 하면 됩니다.

### 4-1. 카카오톡 채널 만들기

1. https://business.kakao.com 접속 → **채널 만들기**
2. 사업자등록번호가 없으면 **"사업자등록번호가 없으신가요?" → 일반 채널 개설** 을 선택
3. 채널 이름 예: `일본어 회화봇`

### 4-2. 내 서버를 인터넷에 공개하기

카카오는 `https://...` 공개 주소로만 접속할 수 있습니다. 로컬 PC 주소는 안 됩니다.

**테스트용 (임시 주소 — 설치 완료)**

```powershell
# PC 서버 실행 후, tools\tunnel.bat 더블클릭 (또는:)
& "C:\Program Files (x86)\cloudflared\cloudflared.exe" tunnel --url http://localhost:8000
```

출력되는 `https://xxxx.trycloudflare.com` 주소를 폰에서 열어보세요.
(실행할 때마다 주소가 새로 발급됩니다. 가입·토큰 불필요)

**정식 배포 (HTTPS 고정 주소)**

👉 **[DEPLOY.md](DEPLOY.md)** — Render 무료 배포 3분 가이드 (`render.yaml` 포함)
포인트: HTTPS라서 녹음·앱 설치·오프라인이 모두 동작. 무료 플랜은 15분 미접속 시 슬립(첫 접속 30~60초)이고, 재배포 때 진도가 초기화될 수 있습니다(유료 디스크로 해결).

- [Render](https://render.com) — Blueprint 배포 (권장)
- [Railway](https://railway.app) — GitHub 연결 자동 감지
- [Fly.io](https://fly.io) — 볼륨으로 진도 보존

### 4-3. 오픈빌더에서 봇 만들기

1. https://i.kakao.com 접속 → 카카오 계정 로그인
2. **봇 만들기 → 카카오톡 챗봇**
3. 만든 채널을 연결

### 4-4. 스킬 등록

봇 설정 → **스킬** → 스킬 추가

| 항목 | 값 |
|---|---|
| 스킬 이름 | 학습하기 |
| URL | `https://내주소/skill` |
| 방식 | POST |

### 4-5. 블록 등록 (⭐ 가장 중요)

시나리오 → **블록 추가**

1. 블록 이름: `학습하기`
2. **발화(대표 문장)**: 아래를 모두 추가
   ```
   시작
   안녕
   메뉴
   커리큘럼
   회화 연습
   말하기 퀴즈
   단어 퀴즈
   오늘의 한마디
   학습 기록
   선생님 바꾸기
   ```
3. **봇 응답**: `스킬데이터 사용` 선택 → 스킬 `학습하기` 선택
4. 저장 후 **배포**

그다음 봇 설정 → **폴백 블록** → 위에서 만든 `학습하기` 블록을 지정하세요.
이렇게 하면 등록하지 않은 문장(예: `1`, `2`, `다음`, `남성`)도 전부 서버로 전달됩니다.

### 4-6. 테스트

카카오톡에서 만든 채널을 친구 추가하고 **"시작"** 을 보내보세요.

> 💡 스킬 서버는 **5초 안에 응답**해야 합니다. 이 봇은 서버 안에서 바로 답하므로 문제없습니다.

## 5. 자주 겪는 문제

| 증상 | 해결 |
|---|---|
| 봇이 "알 수 없는 응답" 이라고 함 | 스킬 URL이 `https` 공개 주소인지 확인 (`http://localhost` 는 불가) |
| `1`, `2` 를 보내도 반응이 없음 | 폴백 블록에 스킬이 연결됐는지 확인 |
| 처음에 선생님을 못 고름 | 폴백 블록 연결 후 다시 시도해보세요 |
| 로컬 화면에서 "서버에 연결하지 못했어요" | `python server.py` 가 실행 중인지 확인 |
| 학습 기록이 초기화됨 | 메모리 저장이라 서버 재시작 시 초기화됩니다 (정상) |
| 콘솔 한글이 깨져 보임 | 표시 문제일 뿐, 실제 데이터는 정상입니다 |

응답 내용을 서버 없이 확인하려면:

```powershell
python tools/smoke_test.py
```
